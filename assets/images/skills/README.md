# Skill logo files

The skill constellation looks for these square PNG files:

- `ja.png` — center image (already included)
- `python.png`
- `java.png`
- `javascript.png`
- `html-css.png`
- `cpp.png`
- `git.png`
- `prisma.png`
- `macos.png`

Use transparent PNGs when possible. A square image around 256 × 256 pixels works well. The website places every logo inside a fixed circle with `object-fit: contain`, so rectangular source images will not escape the circle.

If a file is missing, the website automatically shows the original text initials until you add the logo.
