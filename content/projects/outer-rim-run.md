Outer Rim Run takes the simple jump-and-avoid rhythm of a browser runner and builds a stronger sci-fi identity around it. The game includes eight selectable characters, touch and keyboard controls, increasing speed, procedural hazards, collision detection, and locally saved character and high-score data.

This project taught me that a game can be technically correct and still feel wrong. Jump velocity, gravity, speed, obstacle spacing, and hit areas have to be adjusted together.
