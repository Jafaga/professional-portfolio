I built Expense Tracker to connect a simple desktop interface with real local data. A user can add an expense, review totals by category, filter the transaction list, and delete an entry. Values are validated before they are saved, and money is stored as integer cents to avoid floating-point rounding problems.

The project taught me that the button click is only the visible part of an application. Validation, persistence, calculations, error handling, and refreshing the interface all need to agree.
