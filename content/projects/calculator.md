I built this calculator to make a familiar tool feel clear, comfortable, and dependable. It supports everyday arithmetic, percentages, parentheses, keyboard input, pasted expressions, and light, dark, or system themes.

The Python engine uses Decimal arithmetic and a purpose-built parser instead of executing the expression as code. This project helped me understand how even a small interface depends on careful decisions across input handling, API design, validation, accessibility, testing, and deployment.
