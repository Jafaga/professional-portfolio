Python Pac-Man is a self-contained arcade project with a complete maze, tile-based movement, four ghosts, pellets, power pellets, scoring, lives, collision handling, and generated retro sound. The art and audio are created in code instead of downloaded from an asset pack.

The game made timing and state problems easy to see. A small movement, collision, or reset mistake could change the whole experience, so I learned to examine the loop one system at a time.
