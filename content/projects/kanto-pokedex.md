Kanto Pokédex is a searchable guide to the original 151 Pokémon. The local index appears immediately, while a selected entry combines data from the Pokémon and species endpoints into one specimen file with artwork, descriptions, measurements, abilities, stats, and cry playback.

This project helped me practice turning a large amount of API data into a clear experience. The hard part was not fetching information. It was deciding what belonged together and how someone should move through it.
