01 / OVERVIEW

The project at a glance

The application turns a scattered discovery process into one focused experience for sharing musical interests, finding people, and planning a session.

THE CHALLENGE

Finding compatible musicians was difficult

Students had talent and interest, but no simple campus-focused place to compare skills, tastes, goals, and availability.

THE RESPONSE

Profiles connected discovery to action

Members could present their musical identity, share media, explore other musicians, and create or join available sessions.

THE RESULT

A working community-focused prototype

The team delivered profile and session flows, availability indicators, database-backed content, and improved administrative controls.

02 / CONTRIBUTION

What I designed and built

I worked across the interface and data layers, with an emphasis on helping a new user understand what to do next.

INTERFACE DESIGN

Core user-facing pages

I designed and styled profile views, jam-session pages, and the session-creation experience.

  • Clear page hierarchy and navigation
  • Profile content focused on musical identity
  • Responsive layouts for the main flows
DATA LAYER

Prisma schema and seed data

I helped organize the profile and session data needed by the interface.

  • Contributed to schema decisions
  • Set up and migrated the database
  • Added sample content for testing
SESSION MANAGEMENT

Create, join, and understand availability

I helped implement the session flow and a color-coded system that shows whether a gathering still has room.

ITERATION

User feedback shaped the experience

Feedback led us to strengthen administrative controls and make profile interactions feel more complete.

03 / PROCESS

From student need to usable flow

  1. 01DefineStart with the difficulty of finding musicians, not with a list of technologies.
  2. 02ModelOrganize profiles and sessions in the database before polishing the interface.
  3. 03BuildConnect discovery, profile, creation, and joining into one understandable path.
  4. 04RefineUse feedback to improve status cues, controls, and the overall experience.
04 / TAKEAWAYS

What the project strengthened

ENGINEERING

Full-stack coordination

The project strengthened my ability to connect interface decisions with the structure and behavior of the data behind them.

COLLABORATION

Delivery is a team skill

Dividing work, sharing progress, resolving overlaps, and listening to users affected the result as much as any one feature.

NEXT ITERATION

Future improvements could include group chat, richer scheduling, and expanded profile controls while keeping the path from discovery to connection simple.
