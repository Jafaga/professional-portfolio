01 / OVERVIEW

The project at a glance

This was one of the first Python programs I felt proud of because each change in the logic produced an immediate, visible result.

THE GOAL

Practice control flow with a real input

Use a familiar password-style transformation to practice reading input, visiting each character, making a decision, and building a new string.

THE APPROACH

Apply one rule at a time

The program checks each character against a replacement rule, appends either the transformed or original value, and adds a final symbol.

THE RESULT

A small working command-line utility

The finished exercise made loops, conditionals, and string construction easier for me to understand and modify.

02 / PROGRAM FLOW

Four steps from input to output

  1. 01ReadAccept a word or phrase from the user.
  2. 02IterateVisit each character in order.
  3. 03TransformReplace matching letters with a symbol or number.
  4. 04ReturnPreserve other characters and add the final exclamation point.
03 / IMPLEMENTATION

The core transformation logic

The code is intentionally direct so the control flow remains easy to inspect.

PYTHON

Character-by-character substitution

word = input("Enter a word or phrase: ")
password = ''

for char in word:
    if char == 'a':
        password += '@'
    elif char == 's':
        password += '$'
    elif char == 'i':
        password += '1'
    else:
        password += char

print(password + '!')
DESIGN DECISION

Keep the rule visible

Using explicit conditionals made each branch easy to trace while I was still learning how loops and string concatenation work together.

EXPANSION

Add more substitutions

A later version added rules for letters such as e, o, l, t, and g.

04 / REVIEW

What I learned and what I would improve

LEARNING

Fast feedback built confidence

I could adjust one condition, run the program, and immediately see how the output changed. That made abstract fundamentals feel concrete.

NEXT VERSION

Separate data from control flow

  • Handle empty input safely
  • Preserve capitalization intentionally
  • Move replacements into a dictionary
  • Add repeatable tests
SECURITY NOTE

This is a classroom string-manipulation exercise, not a production password generator. Real credentials should be randomly generated, sufficiently long, and stored with a trusted password manager.
