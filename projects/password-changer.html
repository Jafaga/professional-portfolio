Password Changer

A first-year Python exercise that made loops, conditionals, and string transformation feel concrete.

  • Python
  • Loops
  • Conditionals
  • String Logic
password-changer.reportREAD_ONLY

01. The assignment

This was one of the first Python programs I felt proud of. The program accepts a word or phrase, capitalizes its first character, checks each remaining character, and replaces selected letters with symbols or numbers. It then adds an exclamation point to the result.

The goal was educational: practice iteration, branching, indexes, and building a new string one character at a time. The substitutions resemble familiar “leet” transformations, but the program is a classroom exercise—not a production password generator or a replacement for a password manager.

02. How it works

word = input("Enter a word or phrase: ")
password = ''

for char in word:
    if char == 'a':
        password += '@'
    elif char == 's':
        password += '$'
    elif char == 'i':
        password += '1'
    else:
        password += char

print(password + '!')

Each pass through the loop makes one decision. If a character matches a rule, the transformed value is appended; otherwise, the original character is preserved. A later version expanded the rule set with substitutions for letters such as e, o, l, t, and g.

03. What I learned

The project turned abstract fundamentals into a visible result. I could change one condition, run the program, and immediately see how the output changed. That feedback helped me understand program flow and gave me confidence while Python was still new to me.

04. How I would improve it

A stronger learning version would handle empty input, preserve case intentionally, separate the replacement map from the loop, and include tests. A real security tool would need a very different approach: randomly generated credentials, adequate length and entropy, and secure storage through a trusted password manager.
