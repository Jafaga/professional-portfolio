CASE_STUDY / 01

Jam Sesh-ion!

Connecting UH Mānoa students through music.

The idea

Students have musical talent, but often lack a simple way to discover compatible collaborators. Jam Sesh-ion creates profiles, shares media links, and makes sessions easier to find and manage.

My contribution

I worked across the front end, profile and session interfaces, Prisma data structure, database setup, navigation, and a color-coded availability system. User feedback informed an improved admin experience.

What I learned

Strong team communication and real user feedback are as important as implementation. The project strengthened my ability to balance interface design, data, shared ownership, and practical delivery.

  • Next.js
  • Prisma
  • Vercel
  • Teamwork

CASE_STUDY / 02

Password Changer

Learning Python through a small, concrete transformation problem.

The challenge

Transform a word or phrase into a more complex string by capitalizing characters and replacing familiar letters with symbols or numbers.

The approach

The program loops through user input, evaluates each character with conditional logic, and builds a new result. It became a useful first exercise in string manipulation.

Takeaway

The project made abstract programming fundamentals tangible and gave me confidence during my first year of college.

  • Python
  • String Logic
  • Conditionals

CASE_STUDY / 04

National Cookie Day

Leading a high-school CTE team through commercial bakery production.

The project

I researched bakery operations, planned a large batch for school faculty, organized the workflow, taught classmates how to use the equipment, and helped resolve production issues.

The growth

An early recipe-conversion mistake showed me that good leadership depends on preparation, precise instructions, and clear ownership—not just enthusiasm.

Takeaway

The experience shaped how I approach collaborative work today: prepare carefully, communicate at the team’s pace, and adapt when the plan meets reality.

  • Leadership
  • Planning
  • Communication
